TAG Timestamp Camera - Android WebView
=====================================

Nama aplikasi : TAG Timestamp Camera
Package       : com.tag.timestampcamera
Website       : https://seashell-giraffe-571836.hostingersite.com/

FITUR APK
- WebView HTTPS menuju web app TAG Timestamp Camera
- Izin Kamera Android untuk getUserMedia
- Izin GPS / lokasi
- Geolocation WebView
- Share foto + deskripsi melalui Android Share Sheet / WhatsApp
- Simpan foto blob ke Pictures/TAG Timestamp Camera
- Portrait mode
- Keep screen on selama aplikasi dibuka
- Link WhatsApp / eksternal dibuka melalui aplikasi terkait

BUILD
1. Buka folder ini di Android Studio.
2. Tunggu Gradle Sync selesai.
3. Build > Build APK(s).
4. APK debug berada di app/build/outputs/apk/debug/app-debug.apk

Web app tetap berada di hosting sehingga update PHP/HTML/JS tidak memerlukan build APK ulang selama URL tetap sama.
